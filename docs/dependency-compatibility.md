## pnpm 12 settings

pnpm 12 reads package-manager behaviour from `pnpm-workspace.yaml`; `.npmrc` is registry configuration only. Exact saves, strict engines and peer dependencies are enabled. `verifyDepsBeforeRun: error` prevents a test command silently repairing dependencies. Unreviewed lifecycle scripts remain blocked; the installed `unrs-resolver@1.12.2` postinstall is explicitly allowed. No blanket script permission is used.

The resolver added a package-specific release-age exception for `@testing-library/user-event@14.6.8`. It is exact-version scoped and recorded; `minimumReleaseAgeStrict` prevents automatic future exception additions. Recheck/remove this temporary exception on the next dependency update.
